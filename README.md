# LabAutoload-Software-7

Guia de instalación:

  1- Clonar el repositorio (git clone https://github.com/raspag2005/LabAutoload-Software-7)
  
  2- Entrar a la carpeta del archivo (cd LabAutoload-Software-7)
  
  3- Instalar las dependencias (composer install)
  
  4- Correr prueba.php (php prueba.php)
  


Estructura de archivos:


LabAutoload-Software-7/

│

├── App/

│   └── User.php

├── Database/

│   └── Model/

│       └── ProductModel.php

├── vendor/

├── composer.json

├── composer.lock

├── prueba.php

├── README.md
